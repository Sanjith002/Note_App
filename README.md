# 📝 Note App – Full Stack (React + Node + SQL)

A full-stack note-taking application built using React, Node.js, Express, and SQL. It allows users to manage personal notes with authentication and profile management.

## 🚀 Features

- User authentication (login, signup, logout)
- View and manage user profile
- Upload or update profile image
- Create, edit, and delete notes
- Dashboard to view all notes

- SQL (MySQL / PostgreSQL)
